# ANN-Classification-Churn

## Project Overview

This project implements an Artificial Neural Network (ANN) for customer churn classification using a bank dataset. The goal is to predict whether a customer will leave the bank based on various features.

## Features

- Data preprocessing and feature engineering
- ANN model training and evaluation
- Model saving and prediction
- Experiment tracking and logging

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Dibyajyoti-07/ANN-Classification-Churn.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the main application:
   ```bash
   python app.py
   ```

## Project Structure

- `app.py`: Main application script
- `experiments.ipynb`, `prediction.ipynb`: Jupyter notebooks for experiments and predictions
- `model.h5`: Saved ANN model
- `Churn_Modelling.csv`: Dataset
- `requirements.txt`: Python dependencies
- `logs/`: Training and validation logs
- `myenv/`: Local Python environment (ignored by git)

## Usage

You can use the provided notebooks for experimentation and prediction, or run the main script for training and evaluation.
